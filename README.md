# MORE IS MORE

A maximalist web design showcase built with HTML, CSS, and vanilla JavaScript. Explore bold design directions, customize a poster, and download a design brief as a text file.

Features include responsive layouts, locally hosted fonts, palette and typography controls, and keyboard-friendly navigation with reduced-motion support.

Project files:

- `index.html` — Page content, forms, and dialogs.
- `style.css` — Layout, colors, responsive styles, and font declarations.
- `script.js` — Navigation, poster controls, dialogs, and brief downloads.
- `assets/` — Showcase imagery.
- `fonts/` — Local WOFF fonts and their license information in `LICENSE.txt`.
